Guia de produção

Como gravar, calibrar e registrar cada HB-1. Leia uma vez inteira; depois use só o passo a passo.

Antes de começar Os dois modos Cada unidade Driver do Windows Problemas

Antes de começar

Computador Chrome ou Edge, no computador. Windows, Mac ou Linux. Safari e Firefox não conectam em USB.
Cabo de dados Cabo USB-C que transmite dados. Cabo só de carga liga o LED, mas o PC não vê a placa. Evite hub; ligue direto no PC.
Placa montada Sensor 49E soldado (3V3, GND, GP26) e ímã no lugar. Sem o sensor não dá para calibrar: a leitura fica solta, em torno de 20 %.
Regras de ouro: uma aba do site por vez · sensor montado antes de calibrar · o Zadig, se usar, só em “RP2 Boot (Interface 1)”.

Os dois modos da placa

A mesma placa aparece no computador de dois jeitos diferentes. Saber em qual modo ela está resolve quase todos os problemas.

Modo BOOT · “RP2 Boot”

LED apagado

Placa nova, ou ligada segurando o botão BOOT. Serve só para receber o firmware. Vem de fábrica no chip e nunca se apaga: dá sempre para recomeçar.

Interface 0
Pendrive RPI-RP2
Interface 1
Gravação (PICOBOOT)

Modo HB-1 · “Handbrake HB-1”

LED aceso

Firmware rodando: é assim que o cliente usa. O LED pisca laranja se nunca foi calibrado e fica verde fraco quando está pronto.

Interface 0
Porta serial (COM)
Interface 2
Joystick

No Windows, a porta do HB-1 aparece no Chrome como “HB-1 Config (Interface 0) (COM…)”. No Mac aparece como “Handbrake HB-1”.

Cada unidade, passo a passo

Este é o caminho A da tela de produção: não precisa de driver em nenhum computador.

  1. Entre em modo BOOT

    Segure o botão BOOT da placa, conecte o cabo e solte. Abre um pendrive chamado RPI-RP2 (com um .txt e um .htm dentro, que são normais).

  2. Coloque o firmware

    Na produção, clique em Baixar firmware e arraste o arquivo hb1-….uf2 para o RPI-RP2. O pendrive some e o LED começa a piscar laranja.

  3. Conecte o HB-1

    Clique em Conectar HB-1 e escolha “HB-1 Config (COM…)”. Na primeira vez com cada placa o navegador sempre pergunta: é normal.

  4. Calibre

    Alavanca solta → Gravar repouso. Alavanca no batente → Gravar puxado. Confira o ruído (bom: ±6 ou menos). Se aparecer “curso menor que 400”, ajuste o ímã.

  5. Registre

    Confira série, ID da placa, calibração e data. Clique em Gravar e finalizar. O LED pisca verde 3 vezes.

  6. Etiquete e próxima

    Cole a etiqueta com a série mostrada, desconecte e clique em Próxima unidade. No fim do dia, Baixar CSV.

Caminho B: gravar pelo site

Troca os passos 1 a 3 por um só: segure BOOT, conecte, clique em Procurar placa e escolha “RP2 Boot”. O site grava, confere byte a byte e segue para a calibração. No Windows precisa do driver abaixo, instalado uma vez por computador.

Driver do Windows (só para o caminho B)

O Windows não deixa o navegador usar a gravação do modo BOOT sem o driver WinUSB. Faça uma vez em cada computador de produção. Mac e Linux não precisam. O cliente nunca precisa.

  1. Baixe o Zadig

    Em zadig.akeo.ie. É um programa só, não precisa instalar.

  2. Placa em modo BOOT

    Segure BOOT e conecte. Precisa estar em BOOT (LED apagado, pendrive RPI-RP2 aberto).

  3. Escolha a interface certa

    No Zadig: Options → List All Devices. Na lista, escolha RP2 Boot (Interface 1).

  4. Instale o WinUSB

    À direita da seta verde deve estar WinUSB. Clique em Install Driver e espere. Pronto: não abra mais o Zadig.

Nunca aplique o Zadig em “Handbrake HB-1”, “HB-1 Config” ou “HB-1 Joystick”. Isso tira a porta serial e o site deixa de achar o freio. Se já aconteceu, veja “A lista do Chrome abre vazia” abaixo.

Problemas comuns

O que aconteceO que fazer
O pendrive RPI-RP2 não apareceSegure BOOT antes de conectar e solte depois. Troque o cabo (precisa ser de dados).
A lista do Chrome abre vazia, com o LED piscandoZadig aplicado no HB-1. Zadig → Options → List All Devices → Handbrake HB-1 (Interface 0) → driver USB Serial (CDC) → Replace Driver. Reconecte.
A lista do Chrome abre vazia, com o LED apagadoA placa está em modo BOOT. Arraste o firmware (passo 2) ou reconecte sem segurar BOOT.
“A porta está em uso”Feche as outras abas do site e programas como Arduino IDE, Cura ou monitor serial.
Leitura em ~20 % que oscila e não muda ao puxarSensor não ligado: confira 3V3, GND e o fio OUT no GP26.
“Curso menor que 400”Ímã longe ou fraco. Aproxime ou use um mais forte e grave de novo.
Ruído alto (±15 ou mais)Fio do sensor longo ou perto de fonte de ruído. Capacitor de 100 nF entre 3V3 e GND, perto do sensor.
“Firmware desatualizado” na calibraçãoGrave de novo pelo caminho A ou B antes de calibrar.
Quer apagar tudo e recomeçarEm BOOT, arraste o flash_nuke.uf2 oficial da Raspberry Pi. A placa volta a ser nova (apaga também série e calibração).
